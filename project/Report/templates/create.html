Project Overview This project is a Flask web application designed to provide data analytics and visualizations for the IMDb Top 1000 Movies dataset. The application includes features such as data visualization, movie recommendations, and a survey of movies. The project leverages Flask for the web framework, Pandas for data manipulation, and Plotly for creating interactive visualizations. Thinking Process and Idea The idea for this project stemmed from a desire to create an interactive platform where users can explore and analyze movie data. The IMDb Top 1000 Movies dataset was chosen due to its rich information and popularity among movie enthusiasts.
